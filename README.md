# Hi, I'm Sithabisiwe 👋

Data scientist and lecturer based in Bulawayo, Zimbabwe. I build machine learning and analytics solutions for healthcare and insurance, and I teach statistical programming at NUST.

## What I do
- 🏥 Healthcare ML: multi-modal deep learning on CT imaging (MTech research, HIT)
- 📊 Insurance analytics: explainable AI for premium optimisation
- 🎓 Teaching: R, Python and SQL for university students
- 🔬 Research: systematic review on blockchain in blood supply chains

## Tech stack
**Languages:** R · Python · SQL (PostgreSQL)
**ML & data:** pandas · NumPy · scikit-learn · XGBoost · LSTM · 3D U-Net · SHAP · Grad-CAM · matplotlib · ggplot2 · tidyverse
**Tools:** Git · Jupyter · RStudio · Streamlit · Microsoft 365

## Featured projects
- **Kidney stone CT characterisation**: a deep learning system that segments kidney stones on CT scans, predicts stone composition and recurrence risk, and explains its predictions with a three-tier confidence framework.
- **XAI-POS (Explainable AI Premium Optimisation System)**: a hybrid LSTM-XGBoost pipeline with a Streamlit dashboard that predicts healthcare costs and optimises health insurance premiums within regulatory loss-ratio limits, with SHAP explanations.
- **R, Python & SQL teaching notes**: lecture notes, labs and worked examples used to teach data analysis at university level, including a malaria case study using Zimbabwean districts.

## Open to
Remote and freelance data science work, analytics consulting, and online tutoring in stats, R, Python and SQL.
